# MAIN Game Studio Compatibility Layer

This directory stores MAIN-native state and compatibility assets for the bundled Game Studio pack.

Files:

- `studio.config.json` — persisted studio state such as active engine, review mode, and sticky specialist
- `pack-manifest.json` — installed pack metadata, source, and compatibility inventory
- `hooks/` - scripts for MAIN's supported Game Studio lifecycle checks
