# Bugfix

使用方式：
- 面向 Bug 修复、行为回归、异常状态排查。
- 不要只写现象；必须区分“当前行为”“期望行为”“保持不变的行为”。
- 如果当前是数据分析 / 报表类问题，本文件也可用于记录口径错误、数据异常、报表不一致、统计结果回归等问题。
