# Design

使用方式：
- 设计应服务于 requirements，而不是重复 requirements。
- 如果存在多个方案，优先记录最终选型，并简述为何放弃备选方案。
- 如果用户当前只要方案，也要把执行边界和验证方式写清楚。
- 如果当前是数据分析 / 报表 / 研究类 Plan，本文件代表“分析设计 / 报告设计”，不是默认的代码架构设计。
- 数据分析类设计通常至少覆盖：分析方法、过滤条件、分组维度、报表结构、验证方式。
