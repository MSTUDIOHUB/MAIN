# MAIN 2.2.1 中文 Release Note

版本跨度：2.2.0 -> 2.2.1  
整理日期：2026-05-29

MAIN 2.2.1 是在 2.2.0 之后发布的一轮重要功能拓展与交互体验优化版本。本次更新在延续 2.2.0 稳定版基石的基础之上，聚焦于人机协作和控制流程的深度体验提升。核心亮点收敛于“智能消息队列与流式会话引导”“飞书 IM 会话持久化链接与远程审批”“浏览器自动化工具的精细审批授权与活跃防护”，以及“混合语言自适应感知与解释界面优化”四大方向。这一版本极大增强了长对话下的消息鲁棒性，并在视觉呈现和外部多端联动上完成了极具产品感的跃升。

## 主要更新

### 亮点 1：智能消息队列与流式会话引导能力

- **高可靠消息排队机制 (Message Queuing)**：在流式生成（Streaming Session）处于活跃响应状态时，系统将自动拦截并安全排队用户在此期间的高频输入。这有效防止了并发状态冲突或指令丢失，确保在长文生成期间交互状态始终平稳有序。
- **动态过程运行引导 (Run Guidance)**：新增流式会话中的主动指引和实时状态导向功能，通过智能情境推荐，大幅提升复杂多轮次任务中的协同体验。
- **输入区 (Composer) 视觉风格重构**：全面焕新了 Composer 输入框区域的 UI 色彩主题。新界面采用了更具现代感与深浅和谐度的高级色彩视觉体系，显著优化了日常文字输入时的交互质感和层级感。

### 亮点 2：支持飞书 IM 会话持久化链接与远程审批

- **飞书远程持久化审批 (Feishu Persistent Approval)**：实现了与飞书等即时通讯工具会话的持久化链接适配。当代理发起敏感或重要操作需人工审批时，审批请求会以消息卡片的形式远程推送到绑定的飞书端。审批状态长效同步，允许用户在移动端或飞书界面随时随地进行远程批准，批准后自动热唤醒代理并继续执行。
- **意图总结可见性升级 (Intent Summary Visibility)**：优化了代理当前执行意图在界面中的展示级别与清晰度，使用户在任意交互时刻都能极其醒目且直观地掌控代理当前核心动作的动机。

### 亮点 3：更精细的浏览器自动审批授权与安全防护机制

- **浏览器自动化工具作用域授权 (Auto-approve Scopes)**：允许用户针对浏览器控制与测试验证工具（如网页仿真评估等）配置细粒度的“自动审批作用域”。在自动化测试执行等高频调试场景下，免除弹窗的反复打断，提供极致流畅的全自动网页运行验证。
- **活跃执行态安全隔离锁**：引入了代理执行期间的防误触逻辑。当 Agent 正处于活跃运行中时，系统会自动锁定“自动审核（Auto-review）”等核心安全开关，严禁意外中途关闭，有力规避了因操作失误导致的状态撕裂或执行中断。

### 亮点 4：混合语言智能感知与解释层级体验优化

- **多语言混合排版自适应判定**：升级了复杂文本响应下的回复语言检测机制。针对代码片段与自然语言混杂、中英文高频交织的排版环境进行了更稳健的语义语境解析，防止非预期的语言政策误触发，确保流式输出语言的高度一致。
- **解释面板 UI 渲染流重塑**：细化了轮次解释（Explanation UI）的渐进式刷新与图层展示逻辑，修复了高频更替时可能出现的闪烁或抖动，使代理在进行自我思考过程剖析时，界面的渐现动画更为丝滑。
- **重复调用防护诊断增强**：优化了针对潜在无限循环的重复调用防护机制（Repetition Guard）的分析反馈，当检测到频繁重复行为时，输出更清晰具体的诊断线索，极大便利了日常排障。

## 修复与稳定性

- **IM 消息适配层优化**：改进了多端适配器的数据包解析容错率，确保在极差网络环境下 IM 远程状态同步的绝对可靠。
- **自动审核流程拦截**：优化了在 Agent 工作周期内的交互拦截机制，防止并发状态冲突。
- **界面逻辑去噪**：消除并屏蔽了多处冗余的渲染卡顿和日志噪声，界面响应更迅速。

## 验证覆盖

- **集成与回归测试强化**：
  - 补充了针对飞书 IM 持久化链接、适配器消息映射及远程审批回调的覆盖测试；
  - 扩展了在不同工具作用域授权下的自动审批与重复工具调用防护拦截测试；
  - 增强了流式定时器（streaming-timer）、看门狗哨兵（stream-watchdog）及系统提示词在极端交互状态下的行为健壮性校验；
  - 新增 E2E 流式交互场景下的端到端 Playwright 测试，确保界面及状态机更新严丝合缝。
- **版本合规统一**：
  - 项目配置、应用描述及包配置文件中的版本号已统一校准更新至 `2.2.1`。

## 下载说明

- macOS Apple Silicon 用户：下载 `MAIN_2.2.1_macOS_apple_silicon.zip`
- macOS Intel 用户，或不确定自己芯片型号的用户：下载 `MAIN_2.2.1_macOS_universal.zip`
- Windows 64 位用户：下载 `MAIN_2.2.1_windows_x64.zip`
- `latest.json`、`*_updater_*` 和 `.sig` 文件用于应用内自动更新与签名校验，普通用户手动下载安装时不需要下载这些文件

### macOS 未签名版本下载与打开方法

- 当前 macOS 版本仍属于未完成 Apple Developer 正式签名 / notarization 的分发状态，下载后首次打开时系统可能拦截。
- Apple Silicon 机型优先下载并解压 `MAIN_2.2.1_macOS_apple_silicon.zip`；不确定机型时下载并解压 `MAIN_2.2.1_macOS_universal.zip`。
- 解压后把 `MAIN.app` 拖到 `Applications`。
- Finder 中对 `MAIN.app` 点击右键，选择 `Open`。
- 如果系统仍拦截，到 `System Settings > Privacy & Security` 里点击 `Open Anyway`。
- 如果看到 “damaged and can't be opened” 一类提示，可在终端运行 `xattr -dr com.apple.quarantine /Applications/MAIN.app` 后再尝试打开。
