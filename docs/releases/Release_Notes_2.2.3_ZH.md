# MAIN 2.2.3 中文 Release Note

版本跨度：2.2.2 -> 2.2.3  
整理日期：2026-05-31

MAIN 2.2.3 是在 2.2.2 之后发布的一轮重大功能拓展与底层架构重构版本。本次更新在继续夯实前期版本稳定性的基础之上，聚焦于引入生产力级的“实时网络搜索与深度内容爬取引擎”，并对应用核心底层进行了系统性的模块化升级。核心改动收敛于“实时网络搜索与深度爬取”、“WorkflowEngine 工作流引擎架构重构”、“标签分栏式快捷回复与富文本顶岛”，以及“全局状态切片与高吞吐流式输出优化”四大主线。这一版本极大扩展了 Agent 的外部知识获取广度，并在承载大型项目和高频长文对话时的响应速度与流畅度上实现了跨越式的提升。

## 主要更新

### 亮点 1：全新实时网络搜索与深度内容爬取引擎

- **智能网络搜索与自动引擎容错 (Web Search with Multi-Provider Fallback)**：新增一键开启的网络搜索功能。支持 DuckDuckGo、Bing 及百度等多家主流搜索服务，并首创**搜索引擎智能容错机制**。当主搜索引擎遇到人机验证拦截或网络异常时，系统会自动平滑降级并切换至备用引擎，确保搜索结果的绝对稳定。
- **智能网页内容爬取与 Jina Reader 兜底 (Web Fetch & Jina Fallback)**：新增网页深度抓取工具。当抓取动态网页或遭遇防火墙拦截时，系统将自动触发专有的 Jina Reader 代理抓取通道，最大化网页解析成功率；内置先进的 HTML 噪声消除算法，自动过滤广告、杂乱样式与无用脚本，只向大模型输入纯净的高可读性正文。
- **GitHub 专有链路深度优化 (GitHub-Specific Extraction)**：针对 GitHub 仓库、Blob 代码文件及分支目录树链接进行了深度定制优化，跳过臃肿的网页 DOM 渲染，直接对接轻量 API 进行极速代码与目录树提取。
- **输入区搜索快捷开关与配置面板 (Composer Search UI)**：在 Composer 对话输入区新增了网络搜索开关按钮。用户可以一键开启/关闭网络搜索能力，并可在输入面板中自由指定偏好的搜索引擎与结果上限。

### 亮点 2：下一代 WorkflowEngine 工作流引擎架构与核心状态解耦

- **统一工作流控制引擎 (Unified WorkflowEngine)**：引入专有的工作流核心引擎架构，对对话生命周期、执行流扭转及状态更新逻辑进行高内聚封装。实现了状态机与 UI 交互的深度解耦，极大增强了多轮长任务、断点恢复执行时的流程健壮度，消除了状态漂移导致的执行跑偏。
- **执行卡片智能去重与精炼 (Turn Deduplication)**：工作流引擎新增 Agent 执行块（Block）与步骤自动去重算法，完美消除了长对话中可能出现的冗余历史展示，交互脉络清晰明了。
- **聊天意图视觉净化 (Chat Intent UI Suppression)**：智能识别用户会话意图。当用户仅进行普通闲聊或咨询（Chat Intent）时，系统自动压制并隐藏冗余的“运行步骤”和“状态卡片”，还原纯净利落的极简对话视域。

### 亮点 3：分栏式快捷回复（Quick-Reply）与富文本顶岛通知

- **标签分栏式快捷操作栏 (Tabbed Reply Options UI)**：重构了快捷回复推荐按钮的排版。将不同类型的操作选项（如：计划审批类操作、自然语言快捷追问、执行调整选项）归入标签页分栏管理，防止海量选项按钮在屏幕底部堆叠，大幅提升小屏幕下的界面整洁度与操作便利度。
- **富文本格式化顶岛通知 (Formatted TopIsland Rendering)**：顶岛（TopIsland）通知组件正式支持高级富文本与格式化文本渲染，大幅提升系统状态通知、任务进度及审批指引的视觉精致感与排版信息密度。

### 亮点 4：系统级状态切片重构与超高吞吐流式输出

- **应用状态切片模块化拆分 (Modular State Slicing)**：对全局核心状态库进行了彻底的模块化架构拆分，将工作区状态与系统全局配置进行深度隔离。这大幅减少了 React 组件的无效重复渲染，项目大型化时的 UI 交互流畅度与响应速度提升数倍。
- **高吞吐流式数据拦截器 (Streaming Interceptor & Buffering)**：重构了流式输出的接收缓冲区与渐进式拦截逻辑，实现高频分块数据的微秒级平滑渲染，彻底解决了复杂长文生成时可能出现的字元抖动、卡顿与浏览器线程阻塞。

## 修复与稳定性

- **本地大模型 Escalate 阈值调优**：优化了针对本地模型在极长上下文下的 Escalate 阈值保护，显著改善了本地硬件资源占用。
- **UI 布局细节润色**：精细优化了思考过程折叠栏的动画过渡效果与滚动条隐藏逻辑，提升交互的平滑质感。
- **单元测试完美合规**：通过 670 项回归测试，确保新重构架构的绝对稳定性与功能完整度。

## 下载说明

- macOS Apple Silicon 用户：下载 `MAIN_2.2.3_macOS_apple_silicon.zip`
- macOS Intel 用户，或不确定自己芯片型号的用户：下载 `MAIN_2.2.3_macOS_universal.zip`
- Windows 64 位用户：下载 `MAIN_2.2.3_windows_x64.zip`
- `latest.json`、`*_updater_*` 和 `.sig` 文件用于应用内自动更新与签名校验，普通用户手动下载安装时不需要下载这些文件

### macOS 未签名版本下载与打开方法

- 当前 macOS 版本仍属于未完成 Apple Developer 正式签名 / notarization 的分发状态，下载后首次打开时系统可能拦截。
- Apple Silicon 机型优先下载并解压 `MAIN_2.2.3_macOS_apple_silicon.zip`；不确定机型时下载并解压 `MAIN_2.2.3_macOS_universal.zip`。
- 解压后把 `MAIN.app` 拖到 `Applications`。
- Finder 中对 `MAIN.app` 点击右键，选择 `Open`。
- 如果系统仍拦截，到 `System Settings > Privacy & Security` 里点击 `Open Anyway`。
- If you see a “damaged and can't be opened” message, run `xattr -dr com.apple.quarantine /Applications/MAIN.app` in the terminal and try opening again.
