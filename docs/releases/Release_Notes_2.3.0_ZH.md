## ⚠️ Mac 系统启动问题协商

### 问题描述
在部分 Mac 系统中，MAIN v2.3.0 可能遇到以下启动问题：
- 应用启动后无响应或白屏
- 应用被系统安全机制阻止启动
- 首次启动时权限请求导致卡住

### 协商方案
我们建议用户按以下步骤尝试解决：

1. **检查系统权限**
   - 前往「系统设置」>「隐私与安全性」
   - 查看 MAIN 是否已被添加到允许列表
   - 如被阻止，点击「仍要打开」

2. **清除应用缓存**
   ```bash
   rm -rf ~/Library/Application\ Support/main
   rm -rf ~/Library/Caches/main
   ```

3. **重新安装**
   - 从官网下载最新版本
   - 拖拽到 Applications 文件夹覆盖安装

4. **联系支持**
   - 如问题持续，请提供系统日志
   - 通过 GitHub Issues 或社区论坛反馈

### 我们的承诺
- 正在积极调查此问题的根本原因
- 将在后续版本中彻底解决
- 感谢用户的耐心和理解
