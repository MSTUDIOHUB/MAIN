# MAIN 2.2.6 中文 Release Note

版本跨度：2.2.5 -> 2.2.6  
整理日期：2026-06-05

MAIN 2.2.6 是一轮聚焦于"知识获取自动化"与"执行效率提升"的更新版本。本次更新引入了全新的知识库网络爬虫与 URL 导入功能，支持全局知识库 RAG 检索与 HTML 内容解析；同时实现了 Shell 命令自动审批系统，在保障安全的前提下大幅减少了人工干预次数；此外，还对 Image Studio 设置界面、Git 工作流体验以及应用图标生成流程进行了多项优化与修复。这一版本在知识处理自动化和执行效率上实现了显著跃升。

## 主要更新

### 亮点 1：知识库网络爬虫与 URL 导入功能

- **网页内容自动抓取 (Web Crawler)**：新增了知识库网页爬虫功能，支持通过 URL 自动抓取网页内容并导入 MAIN 知识库。用户只需提供目标链接，系统即可智能提取正文内容、图片与结构化数据，大幅降低了知识收集的门槛。
- **URL 一键导入 (URL Import)**：在知识库管理界面中新增了 URL 导入入口，支持批量添加网页链接并自动解析。导入过程自动过滤导航栏、广告等无关元素，确保知识库内容的纯净度与可用性。
- **HTML 内容解析增强 (HTML Import)**：新增了对 HTML 格式文档的解析支持，能够处理复杂的网页结构、表格、代码块等多媒体内容，并将其转换为结构化知识库条目。

### 亮点 2：全局知识库 RAG 检索与智能路由

- **全局知识库 RAG (Global Knowledge Base RAG)**：实现了跨知识库的统一检索能力。当用户提问时，系统会自动在已导入的所有知识库中搜索相关内容，并将最相关的片段作为上下文注入对话，显著提升了回答的准确性与深度。
- **智能片段匹配**：采用语义相似度算法对知识库内容进行匹配，优先返回与用户问题最相关的片段，并附带来源文件、页码或块号等引用信息，便于用户追溯与验证。

### 亮点 3：Shell 命令自动审批系统

- **自动审批机制 (Shell Auto-Approval)**：新增了 Shell 命令自动审批系统。对于低风险、可预测的命令（如文件读取、目录扫描、构建检查等），系统会自动放行而无需用户手动确认，大幅减少了执行流程中的人工干预次数，提升了 Agent 的工作效率。
- **安全验证增强 (File-Read Validation)**：自动审批系统内置了文件读取验证逻辑，确保自动放行的命令不会访问未授权路径或执行危险操作。所有自动审批的命令均会记录日志，供用户后续审计。
- **智能命令解析 (Improved Command Parsing)**：改进了命令解析引擎，能够更准确地识别命令意图与风险等级，减少误判与漏判。

### 亮点 4：Image Studio 设置界面重构

- **设置向导体验升级 (Setup UI Overhaul)**：对 Image Studio 的设置模态框进行了全面重构。新的界面采用更直观的布局，支持对"本地图片服务"与"HiDream 网页托管"进行精细化配置；新增了一键复制导入 MAIN 本地模型配置、一键测试连接、扫描发现可用生图模型等功能，极大提升了多模态配置的易用性。

### 亮点 5：Git 工作流优化

- **Git 菜单改进 (Git Menu Update)**：优化了 Git 相关菜单的布局与交互逻辑，使分支管理、提交、推送等操作更加直观便捷。
- **提交体验提升 (Commit Experience Update)**：改进了 Git 提交流程中的提示文案与操作反馈，使提交历史更加清晰可读。

## 修复与稳定性

- **应用图标生成缓存 (Icon Generation Cache)**：新增了应用图标生成的缓存逻辑，避免了重复生成相同尺寸的图标，显著缩短了构建与发布流程的耗时。
- **App Store 状态持久化修复 (App Store State Persistence)**：修复了 App Store 状态在应用重启后丢失的问题，确保用户的选择与配置能够正确保存与恢复。
- **MAIN 手册更新**：更新了 MAIN 用户手册，补充了知识库导入、Shell 自动审批等新功能的说明文档。
- **版本合规统一**：项目配置、应用描述及包配置文件中的版本号已统一校准更新至 `2.2.6`。

## 下载说明

- macOS Apple Silicon 用户：下载 `MAIN_2.2.6_macOS_apple_silicon.zip`
- macOS Intel 用户，或不确定自己芯片型号的用户：下载 `MAIN_2.2.6_macOS_universal.zip`
- Windows 64 位用户：下载 `MAIN_2.2.6_windows_x64.zip`
- `latest.json`、`*_updater_*` 和 `.sig` 文件用于应用内自动更新与签名校验，普通用户手动下载安装时不需要下载这些文件

### macOS 未签名版本下载与打开方法

- 当前 macOS 版本仍属于未完成 Apple Developer 正式签名 / notarization 的分发状态，下载后首次打开时系统可能拦截。
- Apple Silicon 机型优先下载并解压 `MAIN_2.2.6_macOS_apple_silicon.zip`；不确定机型时下载并解压 `MAIN_2.2.6_macOS_universal.zip`；
- 解压后把 `MAIN.app` 拖到 `Applications`；
- Finder 中对 `MAIN.app` 点击右键，选择 `Open`；
- 如果系统仍拦截，到 `System Settings > Privacy & Security` 里点击 `Open Anyway`；
- 如果看到 "damaged and can't be opened" 一类提示，可在终端运行 `xattr -dr com.apple.quarantine /Applications/MAIN.app` 后再尝试打开。
