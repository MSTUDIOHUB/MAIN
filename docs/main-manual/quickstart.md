# 快速开始

第一次使用时，先完成三件事：连接模型、打开工作区、发送只读任务。

![快速开始时先确认顶部模型状态，再在左侧添加工作区，最后从底部输入任务。](assets/screenshots/main-workbench.png)

## 适用场景

- 第一次安装 MAIN。
- 已有本地模型或 API Key。
- 想确认 MAIN 能读取项目。

## 前置条件

- 已安装 MAIN。
- 本地模型服务已启动，或已准备云端 API。
- 准备一个安全试用的项目文件夹。

## 步骤

1. 打开 MAIN。
2. 点击顶部模型状态，进入模型设置。
3. 本地模型配置 Provider 和 Endpoint；云端模型新增服务器。
4. 回到主界面，在左侧添加项目文件夹。
5. 发送一个只读任务：

   ```text
   请阅读这个项目的结构，告诉我它是做什么的，并列出最重要的入口文件。
   ```

6. 等 MAIN 输出总结。

## 结果确认

- 顶部模型状态已更新。
- 左侧出现工作区和会话。
- 对话区出现文件读取记录和总结。
- 只读任务不会写入文件。

## 常见问题

**模型列表扫描不到怎么办？**  
确认服务已启动，Endpoint 和端口正确。

**云端测试失败怎么办？**  
检查协议、Endpoint、模型名和 API Key。

**第一次任务要不要改文件？**  
建议先做只读分析，确认稳定后再让 MAIN 修改文件。
