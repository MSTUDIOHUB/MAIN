# MAIN 概览

MAIN 是一个桌面 AI 工作台，用来把聊天、代码理解、文件修改、终端执行、知识检索、图像生成和专业工作流放在同一个项目环境里。

<!-- screenshot: docs/main-manual/assets/overview-main-window.png -->

## 适用场景

- 和 AI 一起理解一个项目、阅读代码、整理文档或做方向探索。
- 让 MAIN 修 bug、实现功能、重构代码、运行测试并解释结果。
- 在写入文件或执行命令前进行人工审批，降低误操作风险。
- 连接本地模型、云端模型、MCP 服务器和知识库，把不同工具统一到同一个工作区。
- 使用图像工作室或游戏工作室完成更具体的创作和研发流程。

## 前置条件

- 已安装 MAIN 桌面应用。
- 至少准备一种模型来源：本地模型服务或云端 API。
- 准备一个项目文件夹，或先从全局聊天开始。

## 你可以用 MAIN 做什么

MAIN 的核心界面由左侧边栏、中间对话区和右侧工作面板组成。左侧管理工作区和会话；中间承载聊天、计划、工具执行记录和审批卡片；右侧用于查看计划、文件、Diff 和终端。

MAIN 不是只回答问题的聊天窗口。它会根据任务主动读取项目文件、搜索文本、分析文档、执行命令、打开 Diff、调用 MCP 工具或检索知识库。对于可能修改工作区的操作，MAIN 会把关键步骤呈现给你审查。

## 步骤

1. 安装并打开 MAIN。
2. 选择本地模型或云端模型。
3. 添加一个工作区，或先进入全局聊天。
4. 选择合适的 MAIN 场景和工作方式。
5. 发送一个清晰任务，并观察 MAIN 的工具记录、审批卡片和最终总结。

## 结果确认

当一次任务完成后，你应该能看到：

- 中间对话区中的结论、改动摘要或下一步建议。
- 工具执行记录，说明 MAIN 读取、修改或验证了什么。
- 如有文件修改，右侧 Diff 或审批卡片会展示变更。
- 如有命令验证，终端或工具记录会显示输出。

## 常见问题

**MAIN 是否必须连接云端模型？**  
不必须。MAIN 支持 LM Studio、Ollama、OMLX 等本地服务，也支持 OpenAI Compatible、Anthropic、Gemini 等云端接口。

**MAIN 会自动修改我的项目吗？**  
读文件和搜索通常会自动执行。写文件、替换内容、运行命令等敏感操作会进入审批流程，除非你明确开启了自动批准。

**MAIN 适合非代码任务吗？**  
适合。你可以用通用协作、创意共创、研究分析、知识库和图像工作室处理文档、资料、视觉概念与结构化分析。
