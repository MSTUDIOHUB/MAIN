# MAIN 场景

MAIN 场景表示“你现在想达成什么目标”，帮助 MAIN 选择更合适的提示词、工具优先级和工作流入口。

<!-- screenshot: docs/main-manual/assets/main-modes-selector.png -->

## 适用场景

- 不确定应该用聊天、代码、研究还是游戏工作流开始。
- 希望 MAIN 根据任务类型调整表达方式和工具选择。
- 在同一个应用里切换普通协作、工程实现、图像或游戏开发任务。

## 前置条件

- 已打开 MAIN。
- 已创建全局聊天或工作区会话。

## 场景说明

`通用协作` 适合空目录起步、提问答疑、轻量 brainstorm、文档整理和方向探索。它是最稳妥的默认入口。

`创意共创` 适合概念发想、内容构思、交互方向、产品叙事和视觉体验探索。它会更关注把灵感收束成可推进的结构。

`工程实现` 适合功能开发、调试修复、重构、代码落地和架构分析。它会更积极地读取代码、定位文件、生成改动并验证。

`研究分析` 适合文档研读、表格分析、数据总结、对比研究和风险提炼。它更偏向只读分析和结论组织。

`游戏工作室` 适合游戏概念启动、GDD、UX、系统设计、引擎配置和跨职能游戏团队协作。它会启用 Studio slash 命令和专业 Agent 入口。

## 步骤

1. 在对话区顶部或输入区附近找到 MAIN 场景切换入口。
2. 选择最接近当前目标的场景。
3. 输入你的任务。
4. 如果任务目标变化明显，先切换场景再继续。

## 结果确认

- 选择游戏工作室时，会出现 Studio 相关 onboarding、命令或专家入口。
- 选择图像相关入口时，会进入图像工作室会话和图片生成设置。
- 普通代码任务在工程实现中更容易触发文件读取、修改和验证链路。

## 常见问题

**MAIN 场景和 Chat / Plan / Fast 是一回事吗？**  
不是。MAIN 场景说明你想做什么；Chat / Plan / Fast 说明 MAIN 应该用什么节奏执行。

**选错场景会损坏项目吗？**  
通常不会。场景主要影响提示词和入口。真正的写入和命令执行仍受审批保护。

**什么时候用通用协作？**  
当你还没想清楚目标，或只是想先聊、问、整理、探索时，用通用协作。
