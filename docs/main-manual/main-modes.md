# MAIN 工作流

MAIN 使用统一入口处理问答、研究、代码、文档、游戏开发和 MCP 工具任务。输入框不再提供场景切换菜单。

## 适用场景

- 提问、讨论、总结或分析资料。
- 修改工作区文件、运行验证或使用已连接的 MCP 工具。
- 长任务先整理计划，审阅批准后执行；后续调整通过新的用户指令继续。

## 前置条件

- 已选择可用模型。
- 修改项目时已打开工作区。
- 需要外部能力时已连接对应 MCP Server。

## 步骤

1. 用自然语言描述目标、范围和限制。
2. 需要先审查方案时选择 `/计划`。
3. 审阅计划，批准后执行。
4. 查看工具结果、Diff 与验证结论，再提出后续指令。

## 结果确认

- 每次提交都有独立回合、工具证据和最终结论。
- 文件写入、命令和外部操作继续受范围与审批约束。
- 普通图片输入、文件附件和截图仍可用于理解与验证。

## 兼容迁移

升级保留普通聊天文本、附件及用户导出的文件。旧的独立长期目标归档为普通聊天，不再自动续跑；已在用户工作区产出的文件保留。旧模式配置不再恢复入口。

## 常见问题

**长任务如何继续？**
先使用计划并批准执行，结束后通过新消息说明剩余需求。

**游戏开发需要专用模式吗？**
不需要。直接描述任务，MAIN 可按需使用已配置的引擎 MCP 工具。
