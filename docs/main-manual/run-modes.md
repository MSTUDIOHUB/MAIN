# 对话与计划

普通任务可以直接发送。需要先审阅方案时使用 `/计划`。希望 MAIN 先和你讨论关键取舍时使用 `/grill-me`。

## 怎么选

- 问答、资料分析和明确的小任务可以直接发送。
- 多文件修改、架构调整、数据迁移等任务适合先使用 `/计划`。在工作区里，目标和范围已经清楚时可以直接形成方案。
- 需要由你决定范围、方法或验收标准时，使用 `/grill-me` 明确要求先访谈。
- 项目规则使用 `/规则`，先审阅修改内容再保存。

## 前置条件

- 已选择可用模型。
- 修改项目时已打开工作区。

## 步骤

1. 描述目标、范围和限制。
2. 如需先规划，选择 `/计划` 或 `/grill-me`，并在有待定问题时提交你的选择。
3. 如果生成了实施计划，审阅并批准对应版本后再执行。
4. 查看工具记录、Diff 和验证结果。
5. 通过后续消息继续调整。

## 结果确认

- 每次发送都成为独立 Turn，并保存可观察的工具证据和最终结论。
- 计划本身不会授予文件写入或命令执行权限。
- 执行仍受工作区范围、源码版本和审批边界约束。

## 常见问题

**长任务会自动无限续跑吗？**
不会。先计划、批准执行，再根据结果发出后续指令。

**讨论过程中可以提出修改吗？**
可以。说明新的目标与限制，MAIN 会按新的用户指令接纳任务。
