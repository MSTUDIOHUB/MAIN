# Chat / Plan / Fast

工作方式决定 MAIN 是先讨论、先规划，还是更直接地推进任务。

<!-- screenshot: docs/main-manual/assets/run-modes-toggle.png -->

## 适用场景

- 想知道一个任务应该先分析还是直接执行。
- 需要在低风险快速修改和高风险审阅之间切换。
- 想让 MAIN 先产出计划，再由你批准。

## 前置条件

- 已打开会话。
- 已选择合适的 MAIN 场景。

## 模式说明

`Chat` 适合问答、分析、研究、总结和低风险讨论。MAIN 可以读取上下文，但不会默认把任务理解成必须修改文件。

`Plan` 适合多文件修改、架构调整、复杂功能和需要先确认方案的任务。MAIN 会先探索，再输出可审阅计划；你批准后才进入执行。

`Fast` 适合明确、低风险、你希望更快推进的任务。它更偏直接执行，但仍会保留必要审批。

## 步骤

1. 先判断任务风险和清晰度。
2. 只想问问题或读资料时选择 Chat。
3. 涉及多文件、架构或不确定需求时选择 Plan。
4. 目标明确、改动小且需要速度时选择 Fast。
5. 发送任务后，根据 MAIN 的确认、计划或审批卡片继续。

## 结果确认

- Chat 更常输出解释、总结和建议。
- Plan 会显示计划面板、任务清单或计划审批入口。
- Fast 会更快进入工具调用、文件修改或命令验证。

## 常见问题

**Plan 模式是不是每次都会创建计划文件？**  
不是。简单分析和轻量任务可以直接回答。复杂任务才会进入更完整的计划流程。

**Fast 会绕过审批吗？**  
不会。Fast 只是执行节奏更快，不代表忽略写入和命令安全。

**任务中途可以切换吗？**  
可以，但建议在新一轮消息前切换。已经开始的执行会以当前回合状态为准。
