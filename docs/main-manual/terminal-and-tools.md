# 终端与工具

MAIN 通过工具连接项目文件、终端、文档、表格、浏览器验证和外部 MCP 服务，让任务结果可观察、可验证。

<!-- screenshot: docs/main-manual/assets/terminal-tools-panel.png -->

## 适用场景

- 让 MAIN 搜索和读取项目文件。
- 运行测试、构建、脚本或开发服务器。
- 分析 PDF、DOCX、CSV、XLSX 等资料。
- 验证本地网页或 UI 状态。

## 前置条件

- 已打开工作区。
- 需要运行命令时，确认项目依赖已安装。
- 需要浏览器验证时，确认目标页面可以本地访问。

## 工具类型

文件工具可以列目录、读文件、搜索文件、按 glob 找文件、提取项目骨架。

文档和表格工具可以读取文档、总结表格、查询大型表格数据。

终端工具可以运行一次性命令，也可以驱动长时间运行的交互式终端。

浏览器验证工具适合检查 DOM、控制台、页面状态和本地 Web 应用行为。

## 步骤

1. 在任务中明确需要验证的方式，例如“请运行测试”或“请打开本地页面检查按钮是否存在”。
2. 当 MAIN 请求命令审批时，确认命令内容。
3. 需要持续运行的命令可以在右侧 Terminal 查看。
4. 对长输出，要求 MAIN 读取最新日志尾部并总结关键错误。
5. 完成后让 MAIN 给出验证结论。

## 结果确认

- 工具块显示已读取、搜索、运行或验证的目标。
- 命令工具返回 exit code、stdout、stderr 或终端日志。
- 浏览器验证会说明检查目标和结果。
- 最终回复引用验证证据，而不是只说“应该可以”。

## 常见问题

**命令一直运行怎么办？**  
打开右侧 Terminal 查看状态。必要时停止生成或要求 MAIN 读取终端尾部日志后判断。

**MAIN 不能访问系统外文件怎么办？**  
MAIN 的项目工具通常受工作区范围限制。把需要分析的文件放入工作区，或通过附件/知识库导入。

**浏览器验证失败怎么办？**  
确认 dev server 已启动、端口正确，页面没有登录或网络依赖阻塞。
