# 第一个工作区

工作区是 MAIN 可以读取、搜索和执行任务的项目文件夹。

![左侧工作区区域用于添加项目，下面是聊天会话和常用入口。](assets/screenshots/main-workbench.png)

## 适用场景

- 第一次添加项目。
- 在多个项目之间切换。
- 用不同会话处理不同任务。

## 前置条件

- 已打开 MAIN。
- 已准备一个本地项目文件夹。
- 只添加你愿意让 MAIN 读取的项目。

## 步骤

1. 点击左侧“新项目”，或拖入文件夹。
2. 选择项目目录。
3. 新建或选择聊天会话。
4. 先发送只读任务，例如“阅读项目结构，不要修改文件”。
5. 切换项目时，回到左侧工作区区域。

## 结果确认

- 左侧显示当前项目。
- 会话记录归属于这个工作区。
- 文件读取和命令默认在该项目内发生。

## 常见问题

**可以不打开工作区直接聊天吗？**  
可以，但涉及项目文件时建议先打开工作区。

**MAIN 会读取整个电脑吗？**  
不会。项目任务默认围绕你选择的工作区。

**同一个项目可以有多个会话吗？**  
可以。不同任务建议拆成不同会话。
