# 第一个工作区

工作区是 MAIN 读取文件、执行命令、保存会话上下文和展示 Git 状态的项目范围。

<!-- screenshot: docs/main-manual/assets/first-workspace-sidebar.png -->

## 适用场景

- 第一次把项目交给 MAIN 阅读或修改。
- 需要在多个项目之间切换。
- 想区分项目内会话和全局聊天。

## 前置条件

- 已经安装 MAIN 并配置好至少一个模型。
- 本机有一个项目文件夹。
- 如果要让 MAIN 修改代码，建议项目已纳入 Git 管理。

## 步骤

1. 在左侧边栏点击添加工作区。
2. 选择一个项目文件夹。
3. 等待工作区出现在左侧列表中。
4. 点击工作区下的新建会话按钮，创建项目会话。
5. 在输入框发送只读任务，例如让 MAIN 总结项目结构。
6. 需要切换项目时，点击左侧其他工作区即可。
7. 不需要项目文件上下文时，可以进入全局聊天。

## 结果确认

- 左侧显示当前工作区名称和会话列表。
- 当前会话会跟随工作区保存，不会和其他工作区混在一起。
- 如果工作区是 Git 仓库，左侧可以显示分支和改动状态。
- 右侧文件面板可以浏览当前工作区文件。

## 常见问题

**全局聊天和工作区会话有什么区别？**  
全局聊天适合不依赖项目文件的问题。工作区会话会让 MAIN 具备读取、搜索和修改当前文件夹的能力。

**一个工作区可以有多个会话吗？**  
可以。你可以为不同任务创建不同会话，避免上下文互相干扰。

**切换工作区会影响旧会话吗？**  
不会。MAIN 会按工作区保存会话索引，之后可以回到原工作区继续。
