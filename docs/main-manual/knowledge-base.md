# 知识库

知识库是可跨项目使用的个人资料库。导入资料建立本地索引后，在聊天输入 `#` 搜索并多选整库或单篇资料；选中的标签仅随当前消息提交，下一条消息默认不继续绑定。

工作区可启用匹配引擎的官方手册。MAIN 先查本地正文，未命中时按官方目录补齐页面。网络搜索关闭时，目录匹配在本地完成，页面可从官方站点下载。搜索服务仅在网络搜索开启、前两层未命中且该次查询请求联网兜底时使用。显式 `#` 选取资料的首轮预检索只查本地。

## 使用步骤

1. 打开知识库，新建资料库并导入文件或网页。
2. 确认资料状态为已索引；解析失败和需要 OCR 的资料不会假装可用。
3. 在聊天中输入 `#`，选择整库或具体资料，然后提出问题。
4. MAIN 在首次模型请求前自动检索所选范围，无需模型先决定调用检索工具。
5. 展开本轮资料面板，核对来源、页码、片段和覆盖范围。

普通 Markdown 标题不会成为资料选择。没有选择资料时不检索，也不会自动搜索所有已启用的旧资料库。

## 检索范围

当前使用本地中英文词面检索，不需要额外嵌入模型，不承诺同义表达的语义召回。返回片段与引用共同受上下文预算约束，不把整库全文塞给模型。

单篇资料没有关键词命中时，可提供明确标注的有限开头概览；这不是相关度命中，也不代表已阅读整篇。资料更新、重建或删除后，旧选择会要求重新选择，避免默默换成其他版本。

## 常见问题

**导入后没有可用内容怎么办？**
检查解析状态。扫描 PDF 可能需要 OCR；导入失败、空文档与无搜索命中是不同情况。

**资料中的指令会自动生效吗？**
不会。资料作为参考内容，不能成为项目约束、工具授权或验证通过证据。

**一次性小文件需要入库吗？**
不需要，可直接使用附件或工作区文件引用。
