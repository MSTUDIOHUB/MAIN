# MAIN 1.5.7 中文 Release Note

版本跨度：1.5.5 -> 1.5.7  
整理日期：2026-05-07

## 下载页短摘要

MAIN 1.5.7 重点补强了“长会话可恢复性”“云端模型兼容性”和“项目首开空会话体验”。新版把项目会话的保存、恢复和分页加载做得更稳，切换超长历史会话时能优先秒开最近内容，再按需继续加载更早记录；同时新增云端 Tool Protocol 选项，能在原生 tools 与 XML 工具协议之间按网关兼容性切换，并进一步收敛首屏空状态表现，让打包版进入项目时保持真正的空会话，不再预置示例内容或推荐提示。

## 下载说明

## 主要更新

### 会话记录与超长历史恢复

- 项目会话持久化结构进一步完善，消息和回合记录改为更稳的 JSONL 读写流程，并补充原子写入，降低长会话保存过程中的损坏风险。
- 新增会话元信息与分页读取接口，切换到 300+ 回合的历史会话时会优先加载最近一页内容，减少首次打开等待时间。
- 聊天区支持“加载更早历史”，可以按页继续向前补齐更早回合，而不是一次性把整段长历史全部塞回前端。
- 会话恢复增加多级回退逻辑：优先使用当前活跃运行态，其次使用缓存分页记录，再回退到磁盘 transcript；即使旧数据只剩 `agentMessages`，也能尽量恢复出可读对话。
- 修复新建但尚未发送的临时会话容易被显示成 `Missing Session` 的问题；删除当前空会话后，也会更准确地回到上一条有效会话。
- 切换会话时会同步重置右侧 Diff / 文件 / 终端面板，避免把上一条会话的界面状态错误带到下一条会话。

### 项目首开空会话体验

- 打包后的项目工作区在首次进入时会保持空会话状态，不再自动塞入任何示例内容、历史残留或推荐提示。
- 当当前持久化状态里已经没有有效会话时，界面会主动清空旧 runtime，而不是把上一轮聊天内容误恢复到新项目首屏。
- 全局聊天与项目聊天的空状态表现进一步统一，空白页只保留简洁标识，避免用户误以为安装包内自带预设对话内容。

### 云端模型协议与工具兼容性

- Cloud Settings 新增 `Tool Protocol` 选项，可在 `Auto`、`Native`、`XML` 之间切换，方便针对不同云网关的 function calling 兼容性做显式控制。
- `Auto` 模式会优先尝试原生 tools，遇到兼容性较弱的网关时可回退 XML；`XML` 模式则会直接禁用原生 tools，仅走文本工具协议。
- OpenAI Responses 请求构造进一步统一，补充更稳定的 request candidate 构建方式，继续保留 `store: false`、`reasoning.effort` 与顶层 `instructions` 等兼容处理。
- 新增模型指令画像推断，可按 Anthropic、Qwen、DeepSeek、Kimi 等不同提供商特征决定思维显示、工具偏好与降噪策略。
- Anthropic 流式处理新增 `thinking_delta` 解析，思考内容会更清晰地落入隐藏 thought 通道，而不是混进用户可见正文。

### 流式输出、滚动与文件查看

- 顶部运行计时器重构为独立组件，跨会话切换与连续流式执行时的计时显示更稳定。
- 优化高频流式输出时的聊天滚动响应，历史区域在快速增量输出过程中仍可顺畅手动上滚查看，不容易被持续抢焦点。
- 文件查看器升级为窗口化读取大文件，默认按段展示当前行区间，并支持“加载下一段”继续展开，避免一次性打开超长文件造成界面卡顿或内容过载。
- `read_file` 工具执行链路优先接入 Tauri `read_file_window`，让模型读取大文件时也能得到更准确的行号、截断状态与下一次读取建议。
- `MarkdownRenderer` 等高频渲染区域加入记忆化处理，减少流式期间的重复重绘开销。

### 桌面端与状态管理

- 版本号更新到 `1.5.7`，Tauri 与前端版本保持同步。
- 会话 runtime snapshot 新增 transcript 加载状态、文件查看窗口状态等字段，长会话恢复与 UI 面板同步更完整。
- 侧边栏、设置页和 E2E 场景种子同步更新，确保新的会话恢复逻辑、云端工具协议和流式交互都能在回归测试里被覆盖。
- 桌面资源与应用图标一并更新，为后续公开发布保持产物一致性。

## 修复与稳定性

- 修复部分历史会话在磁盘 transcript 缺失、runtime 残缺或旧格式数据下无法正确恢复的问题。
- 修复会话切换后仍残留旧 Diff / 文件面板内容、影响当前会话阅读的问题。
- 改进超长会话首屏恢复速度，避免为了恢复全部历史而阻塞当前会话打开。
- 改进云端 Responses 请求在 XML 工具协议场景下的工具发送策略，减少弱兼容网关报错。
- 改进 Anthropic thinking 流与可见正文的分离，减少思维文本直接泄露到主回答中的噪声。
- 补充会话分页、新建会话、空会话删除、流式滚动、大文件分段查看、云端协议构造与工具协议路由的 node/e2e 回归测试。

## 推荐展示文案

MAIN 1.5.7 是一次围绕“长会话更稳、云端接入更顺、首开体验更干净”的增强更新。它让超长项目会话的保存、恢复和分页查看更可靠，切换历史记录时能更快回到最近上下文；同时新增云端 Tool Protocol 选项，改进多家模型网关下的工具兼容性与思维流处理，并把打包版进入项目时的首屏状态收敛为真正的空会话。配合流式计时、滚动响应和大文件分段查看的优化，这一版更适合真实项目中的长任务、长历史和多模型协作场景。
