# MAIN 1.5.0 中文 Release Note

版本跨度：1.4.3 -> 1.5.0  
整理日期：2026-05-04

## 下载页短摘要

MAIN 1.5.0 重点提升了计划执行的可靠性、远程审批体验和界面可读性。新版加入了更严格的计划任务审计机制，只有存在可信文件、命令或交付物证据时才会标记任务完成；飞书远程工具审批升级为交互式卡片，可直接点击允许或拒绝；同时补强了 Diff 撤销、附件拖拽上传、黑色主题、思考过程显示和 Git 提交推送识别。公开发布流程也更新为自动生成包含提交摘要和变更文件列表的 Release Notes，方便在下载页展示版本变化。

## 主要更新

### 计划执行与任务审计

- 计划批准后会进入真正的执行能力，写文件和命令工具会按执行阶段开放，同时仍保留逐项审查机制。
- 新增计划执行恢复与审计逻辑，防止模型只用文字声明“已完成”却没有真实证据。
- `tasks.md` 会作为执行审计记录使用，任务完成需要匹配文件、命令或交付物证据。
- 改进 TopIsland 和计划面板中的执行进度、剩余任务和完成状态反馈。
- 修正已批准计划在云模型下仍被当作纯 plan 意图过滤工具的问题，减少“工具不可用”的误判。

### 飞书远程审批

- 飞书远程工具审批从文字验证码升级为交互式卡片。
- 卡片支持“允许本次”和“拒绝执行”按钮，并会在处理后自动更新为已允许、已拒绝或已过期状态。
- 审批加入一次性 nonce、过期时间和用户/会话校验，避免旧按钮或错误用户重复操作。
- `/approve CODE` 和 `/reject CODE` 仍保留为卡片不可达时的兜底方式。
- 飞书配置说明补充了 `card.action.trigger` 事件订阅要求。

### 文件修改与 Diff 体验

- Diff 面板支持安全撤销单个文件或全部文件的 AI 修改。
- AI 新建文件可以通过撤销操作删除；已有文件会先检查当前内容，避免覆盖用户后续手动改动。
- Diff 摘要在页面刷新后仍可点击恢复查看。
- 多文件变更摘要、二进制文件提示和计划文件刷新流程更稳定。

### 附件与输入体验

- Composer 支持附件上传和拖拽文件导入，远程与本地上下文处理更顺滑。
- 修复中文输入法组合输入时快捷意图可能丢失的问题。
- 多行用户消息会按原始换行展示。
- 新增 `Shift+Tab` 快捷键，可在 MAIN 输入框中快速切换计划意图。
- Git 状态检查、commit、push 等请求会被识别为需要执行能力的操作。

### 界面与可读性

- 新增黑色外观模式，并同步优化侧边栏、右侧面板、终端、文件查看器、Markdown 代码块和 Mermaid 图表配色。
- 新增“思考显示”设置，可选择隐藏、简洁或详细显示过滤后的模型后台过程。
- 后台思考会过滤重复、噪声、工具日志和大段代码，避免原始长文本刷屏。
- 当模型只有隐藏思考但没有可见结论时，会自动要求补充面向用户的 Markdown 结论。
- 空会话、计划状态切换和执行反馈的界面状态更清晰。

### 发布与分发

- 版本号更新到 1.5.0。
- macOS 发布同时支持 Universal 包和 Apple Silicon 独立包。
- 公开 Release Notes 会自动写入提交摘要、提交正文和变更文件列表，但不会公开源码 diff。
- 公开发布流程不再上传 `SHA256SUMS.txt` 附件，文档已同步更新。
- Playwright 测试支持通过环境变量指定浏览器 channel，便于不同机器运行回归测试。

## 修复与稳定性

- 改进隐藏思考、缺失工具调用、工具不可用声明等场景下的自动追问与恢复。
- 改进计划执行时 shell 命令提示，诊断命令优先使用内联 `run_command`，减少临时脚本污染项目根目录。
- 修复计划完成后运行态清理、空聊天视图重置、右侧面板状态恢复等细节问题。
- 补充 Feishu、云工具协议、计划恢复、任务审计、思考显示、黑色主题、Composer 快捷键和发布脚本的 node/e2e 回归测试。

## 推荐展示文案

MAIN 1.5.0 是一次面向“可靠执行”和“远程协作”的增强版本。计划模式现在会更严格地追踪任务证据，飞书远程审批支持交互卡片，Diff 修改可以安全撤销；同时新增黑色主题、思考显示设置、附件拖拽上传和更稳的 Git/命令执行识别。这个版本更适合长任务、远程审批和需要可追溯执行记录的工作流。
