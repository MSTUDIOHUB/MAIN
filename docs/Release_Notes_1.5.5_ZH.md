# MAIN 1.5.5 中文 Release Note

版本跨度：1.5.0 -> 1.5.5  
整理日期：2026-05-05

## 下载页短摘要

MAIN 1.5.5 重点补强了“真实工作区执行”和“长上下文可靠性”。新版在侧边栏加入工作区 Git 菜单，可直接查看仓库状态、预览 Diff、生成提交信息、提交、推送和创建分支；同时增强了上下文压缩、重复工具调用防护、计划执行证据审计和大文件读取窗口，减少模型在长任务中反复读同一内容、错误宣称完成或被大文件撑爆上下文。发布流程也升级为同时产出手动下载包和 Tauri 自动更新包，并生成 `latest.json` 供应用内更新使用。

## 主要更新

### 工作区 Git 菜单

- 侧边栏新增工作区 Git 入口，可在每个工作区旁查看当前分支、upstream、ahead/behind、变更数量和冲突状态。
- 支持直接打开 Git Diff 预览，查看文件级变更、二进制文件提示和增删行统计。
- 支持生成 Git commit message：优先调用当前模型生成简洁提交标题，失败时自动使用本地 fallback 摘要。
- 支持一键 `git add -A` + `git commit -m`、推送当前分支、创建并切换新分支。
- 新增 Git IPC 能力：状态读取、文件列表、Diff 采集、提交、推送和分支创建都通过 Tauri 后端执行，并带有超时和错误信息归一化。

### 上下文压缩与防重复

- 上下文压缩新增 token 来源拆分，可区分 system、用户上下文、助手可见回复、工具结果、图片、多模态和压缩记忆。
- 压缩摘要更适合长任务恢复，保留最近上下文和关键执行证据，减少历史消息被粗暴丢弃后导致的误判。
- 新增重复工具调用防护，识别同一 read-only 工具或同一目标文件/命令被反复调用的循环，并自动提示模型复用已有结果。
- 思考显示继续优化去重和噪声过滤，减少后台过程摘要里重复出现同一结论。

### 工具执行与大文件读取

- `read_file` 支持窗口化读取大文件，返回起止行、总行数、是否截断和下一次读取建议，避免一次性塞入过多内容。
- shell 工具新增执行契约：`run_command` / `execute_command` 需要提供 `description` 和工作区相对 `cwd`，减少命令在错误目录运行。
- 增加危险 shell 命令识别，强化对破坏性命令的审查。
- 工具 schema、工具能力过滤和系统提示同步更新，强调有限命令优先使用 `run_command`，并明确 Git 工作流可通过执行工具完成。

### 计划执行与证据审计

- 计划执行恢复逻辑进一步加强，避免模型在没有真实文件、命令或交付物证据时把任务标为完成。
- 计划任务可通过明确文件验证读取来满足证据要求，但 `.MAIN` 内部计划文件不会被误当成项目源码交付物。
- TopIsland 执行进度、计划面板和恢复提示更清楚地区分计划状态、执行状态和等待用户选择状态。
- 执行合约要求模型在长任务里先收集证据，再更新任务状态，减少“假完成”和循环执行。

### 游戏开发与 Game Studio

- 新增游戏开发意图识别，能够根据用户文本和项目结构判断 Unity、Godot、Unreal 或不明确的游戏引擎上下文。
- Game Studio catalog 和内置协议包补充引擎识别、设置引擎和项目初始化相关逻辑。
- 对含游戏开发关键词的请求，系统会更主动建议进入对应的 Game Studio 工作流。

### 发布与自动更新

- 版本号更新到 1.5.5。
- 桌面发布 workflow 新增 Tauri updater 签名检查，缺少签名私钥或密码时会提前失败，避免发布无法自动更新的版本。
- macOS / Windows workflow 会生成手动下载 zip、自动更新包、`.sig` 签名文件和 `latest.json`。
- Release 页面继续显示提交摘要和变更文件列表，`latest.json` 公开用于应用内自动更新，不包含源码。
- `release:desktop` 预检补充 updater 签名 Secrets 要求，文档同步说明自动更新产物和配置方式。

## 修复与稳定性

- 修复部分 awaiting choice / quick reply 场景下选项重复或状态显示不准确的问题。
- 改进云模型工具协议，减少 native tools 与 XML tools 回退过程中的工具不可用误判。
- 改进计划 artifact hydration，重新加载计划文件后能更准确恢复 requirements、design、tasks 和 bugfix 状态。
- 改进 Diff 处理和 TopIsland 执行步骤展示，避免计划快捷入口覆盖真实执行进度。
- 补充 Git 菜单、上下文压缩、大文件读取、重复调用防护、工具执行契约、Game Studio 意图、自动更新配置和工作流资产的 node/e2e 回归测试。

## 推荐展示文案

MAIN 1.5.5 是一次面向真实项目落地的增强版本。它把 Git 操作带进工作区侧边栏，让查看变更、生成提交信息、提交、推送和创建分支更顺手；同时通过上下文压缩、重复调用防护、大文件窗口读取和计划证据审计，让长任务执行更稳、更可追溯。发布流程也开始产出 Tauri 自动更新所需的签名更新包和 `latest.json`，为后续应用内自动更新做好准备。
