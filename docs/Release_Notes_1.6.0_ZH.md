# MAIN 1.6.0 中文 Release Note

版本跨度：1.5.9 -> 1.6.0  
整理日期：2026-05-08

## 下载页短摘要

MAIN 1.6.0 重点优化了“MAIN 输入意图体验”“会话级执行审批粒度”和“本地推理兼容配置”。新版不再把 `/执行` 作为默认可见快捷入口，鼓励直接用自然语言下达执行任务；同时把“本会话自动允许”从粗粒度放宽改为“仅自动允许写入与命令”，高风险动作仍逐项审查；本地设置也新增 Tool Protocol 兼容项，可按不同 provider 自动切到更稳的本地协议策略，减少弱兼容网关下的工具调用异常。

## 下载说明

- macOS Apple Silicon（M1 / M2 / M3 / M4）用户：下载 `MAIN_1.6.0_macOS_apple_silicon.zip`
- macOS Intel 用户，或不确定自己芯片型号的用户：下载 `MAIN_1.6.0_macOS_universal.zip`
- Windows 64 位用户：下载 `MAIN_1.6.0_windows_x64.zip`
- `latest.json`、`*_updater_*` 和 `.sig` 文件用于应用内自动更新与签名校验，普通用户手动下载安装时不需要下载这些文件

## 主要更新

### MAIN 输入与快捷入口体验

- MAIN 模式文案进一步收敛为“先判断讨论 / 规划 / 执行，再决定输出格式”，减少把分析、总结、报告误当成独立执行流的问题。
- Slash 快捷入口默认隐藏 `/执行`，保留“先给方案 / 分析 / 总结 / 报告”等更常用入口；但解析层仍兼容 `/执行` 指令，老习惯不会失效。
- 中文执行意图识别补强了“帮我修改 / 改一下 / 处理一下”这类高频表达，更容易直接进入执行流而不是反复确认。
- Composer 提示文案改为“自然语言优先、快捷入口可选”，减少新用户把“必须先切模式”当成硬前提。

### 会话级审批粒度升级

- “本会话自动允许”改为作用域模型：默认仅自动允许 `workspace_write` 与 `shell` 两类后续动作，不再一刀切放开所有工具。
- 高风险动作依然保持逐项审查，不会被会话级自动允许跳过。
- 工作区外本地文件读取（`local_file_read`）仍必须按文件路径首次批准，不受会话级自动允许影响。
- 会话切换、工作区切换和恢复空状态时，会同步清空自动允许作用域，避免把上一会话的审批状态误带到新上下文。
- Action Card 与 TopIsland 的审批文案同步更新，明确“本会话自动允许写入与命令（高风险仍逐项审查）”。

### 本地推理兼容设置增强

- Local 设置新增折叠式“详细设置”面板，并提供本地 Tool Protocol 选择项（`Auto / Native / XML`）。
- 新增 provider 级默认协议：
  - `LM Studio` 默认 `XML`
  - `Ollama` 默认 `XML`
  - `OMLX` 默认 `Auto`
- 切换本地 provider 时会同步重置 endpoint、model 与 tool protocol，减少旧配置残留带来的错配。
- 本地模型下拉新增“未选择模型”占位，避免在 provider 切换时误保留旧模型值。
- Ollama 场景补充说明：继续走 `/api/chat` 文本工具模式，不发送 OpenAI native tools 参数。

### 协议兼容与稳定性

- OpenAI 兼容历史消息里的 `tool_calls.function.arguments` 统一保持 JSON 字符串，避免某些网关因 `messages` 结构不兼容而拒绝请求。
- Provider 兼容错误识别新增 `invalid messages` 类报错模式，能更早触发兼容回退。
- Orchestrator 统一本地与云端的有效 Tool Protocol 解析逻辑，并在 XML 兼容路径下提前转换消息结构，降低弱兼容网关下的失败率。
- Preflight 预检链路同步接入本地 Tool Protocol 归一化，保持预检与正式执行的协议一致性。

### 回复选项与思考显示降噪

- Reply options 现在会过滤“切换到执行模式”“我要调用工具”这类内部过程型伪选项，保留用户可直接点击执行的真实动作选项。
- Thought display 新增“模式抱怨类”噪声过滤，减少反复出现的“当前 discuss 模式不可写入”等自述文本干扰阅读。

## 修复与稳定性

- 修复部分 OpenAI 兼容网关因 `messages` / `tools` 结构敏感导致的请求失败。
- 改进弱兼容网关下的自动协议回退判定，减少“工具可用但请求被拒”后的重复尝试。
- 改进本地 provider 切换后的配置一致性，降低 endpoint、模型、协议互相错位的概率。
- 改进执行审批状态在多会话、多工作区切换时的隔离边界。

## 验证覆盖

- 新增 / 补充 Node 测试，覆盖本地 Tool Protocol 默认值与归一化、`/执行` 隐藏但兼容解析、回复选项伪动作过滤、思考降噪、provider 兼容错误识别，以及 OpenAI 兼容消息的 tool arguments 序列化。
- 新增 / 补充 Playwright E2E，覆盖本地设置中的 Tool Protocol 面板、provider 切换联动、MAIN 快捷入口展示顺序与意图锁定行为。

## 推荐展示文案

MAIN 1.6.0 是一次围绕“自然语言执行更顺、审批边界更清、本地兼容更稳”的增强更新。它让 MAIN 模式减少了对显式模式切换的依赖，用户直接说任务就能更稳定地进入对应意图；同时把会话级自动允许收敛为写入与命令作用域，高风险动作继续逐项审查；配合本地 Tool Protocol 设置和兼容回退优化，这一版在本地与云端混合使用时会更稳、更可控。
